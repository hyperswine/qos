## Step 4: the bundle

Built in `debian:trixie` (glibc 2.41) from clean `git archive` exports and the pinned fprisc
export: Main with six apps and seed disk, `qosp-es` with ALSA, `runner`, `kms-readback`, the
Editor compiler, `qos-fprd`, the SDK, and the physical qualification bundle. Faults found and
fixed on the way:

- **The SDK named every bundled library with a leading tab** (`compiler-sdk-libs.sol` split
  `ldd` lines with `Str.words`, which does not split on tabs), so no library could load and libc
  escaped the system-library filter. Fixed: 58 libraries, libc excluded, 138 MB unpacked.
- **The daemon could not find `libgmp` or `make` on the device.** It is now linked with a
  `$ORIGIN/../lib` runpath, and it resolves a child's bare command name on the child's `PATH`
  (GHC's `process` searches the parent's). The container hid both: it has a system `libgmp` and
  `make`.
- **Two qualification programs no longer build at this pin.** `tests/portableshutdown.fpr` and
  `tests/powercut.fpr` pinned a `std/lifecycle` that `8134237` changed without re-pinning (now
  re-pinned), and `portableshutdown` and `qsys` then fail the 0.14.0 safety line inside
  committed store blobs and `std/blockio`/`programs/mods/appsep` (functions that need an
  `unsafe` signature, or carry one they no longer need). Fixing those changes pinned module
  versions, so the two are left out of this bundle (`QOS_PI4_SKIP=portableshutdown,qsys`) and
  their cases are reported as skipped.

## Step 5: the qualification drivers, in Sol

`tools/pi4/check.sol` (physical runtime qualification), `tools/pi4/main-soak.sol` (isolated Main
with key input), `tools/pi4/soak.sol` (installed observation) and `tools/pi4/hdmi-readback.sol`
replace the retired Python drivers. They run on the Mac and reach the Pi over SSH; `remote.sol`
holds the shared SSH, evdev and evidence helpers. Not ported: `check.py`'s forwarded four-peer
binary TCP case (it needs concurrent socket clients on the Mac) and its `--performance` governor
switch; the device stays at its `powersave` governor, so `mvuscoped` (20,000 cross-actor frames,
about 75 s at 600 MHz) gets a 180 s deadline.
