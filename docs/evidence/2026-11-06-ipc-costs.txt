IPC cost measurements for docs/2026-11-06-ZERO-OVERHEAD-OS-AMENDED.md
Host: arm64 macOS (Apple silicon). QOS f2c3a63, sibling fprisc aee02d8 (codegen 204);
the release lock still names 1a09f01, so these are not the release pin's results.
Each block is one run; no run was repeated more than twice.
