# Two-actor Spectre board probe

Build in a scratch directory with the pinned FP-RISC runtime. This uses the
real single-hart actor scheduler, mailbox, buddy allocator and context switch;
the C entry points are a test application, not a booted QOS desktop or services.
The actor plane is owned by FP-RISC and is the one QOS Native uses.

    QOS=/path/to/qos
    FPRISC=/path/to/fprisc
    mkdir -p src
    pin=$(python3 -c 'import sys,json;print(json.load(open(sys.argv[1]))["revision"])' "$QOS/fprisc.lock.json")
    git -C "$FPRISC" archive "$pin" runtime machine/virt machine/tangnano20k | tar -x -C src
    cp "$QOS"/hal/spectre/actors/{atomic.c,probe.c} .
    sol "$QOS"/hal/spectre/actors/build.sol . probe
    python3 /path/to/simple-risc/boards/tangnano20k/run_program.py --freq-mhz 54 --protocol u --timeout 45 probe.bin

The hardware clock adapter is for the 54 MHz preset. Check the ROM identity
before upload. The scheduler drains its CLINT deadline queue on scheduler
turns: this test checks a timed park while the worker remains runnable, not
interrupt-driven preemption. Three distinct pings and replies are checked.
The parent samples progress after receiving each reply and immediately before
sleeping; it requires both an elapsed 10 ms deadline and further peer progress
on return. DONE after the success marker is generated by the probe. The probe
parks there; the next identity query sends Ctrl-C to re-enter the ROM.

Only single-hart RMW helpers are provided. Register x27 is reserved for fuel.
No relaxation or small-data gp addressing is allowed since the runtime's fresh
actor contexts do not initialize gp. RV32 warnings in the runtime's region
sequence packing are outside this narrow exercise; this is not a qualification
of all runtime features. TEST_QEMU uses virt's UART and 10 MHz CLINT.

## Arty S7-50

The probe also runs on Simple-Risc's Arty S7-50 DDR3 image
(`boards/artys7/pipeline`, preset `arty-s7-81`: CPU 81 MHz, memory 80 MHz).
The clock adapter takes the CPU clock as `CORE_MHZ` (default 54), and the
Arty's serial bridge needs the settle delay after the port opens:

    EXTRA=-DCORE_MHZ=81 sol "$QOS"/hal/spectre/actors/build.sol . probe
    openFPGALoader -b arty_s7_50 <simple-risc>/output/artys7/pipeline-81/top.bit
    SIMPLE_RISC_PORT_SETTLE=1 python3 /path/to/simple-risc/boards/tangnano20k/run_program.py \
      --port /dev/cu.usbserial-<serial>1 --freq-mhz 81 --protocol u --timeout 45 probe.bin
